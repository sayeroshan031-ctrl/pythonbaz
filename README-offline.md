# آزمایشگاه پایتون‌باز — اجرای آفلاین و بدون فیلترشکن (v4)

## چه چیزی تغییر کرد؟

- **موتور پایتون از خود سایت بارگیری می‌شود.** worker اول `vendor/pyodide/` را امتحان می‌کند و فقط اگر آن نبود، سراغ CDN (jsdelivr) می‌رود. پس برای کاربر بدون فیلترشکن، دیگر به jsdelivr وابسته نیستیم.
- **آفلاین واقعی.** Service Worker حالا علاوه بر موتور، خود صفحه (`index.html`)، worker، manifest و آیکن را هم ذخیره می‌کند. بعد از یک بار باز کردن سایت با اینترنت (و یک بار اجرای آزمایشگاه یا زدن «بارگیری / اتصال دوباره»)، سایت و آزمایشگاه بدون اینترنت هم باز می‌شوند. صفحه قابل «افزودن به صفحه اصلی» هم هست.
- **کدهای شی‌گرا و بازی‌ها:**
  - هر اجرا در فضای نام تازه انجام می‌شود؛ کلاس و متغیر اجرای قبلی باقی نمی‌ماند و `if __name__ == "__main__":` درست کار می‌کند.
  - برای `input()` زنده، برنامه از اول دوباره اجرا می‌شود. حالا `random` در هر بار اجرای مجدد seed ثابت دارد، پس بازی‌های حدس عدد و مشابه وسط کار عوض نمی‌شوند.
  - تشخیص «برنامه منتظر ورودی است» دیگر به خطای `EOFError` وابسته نیست؛ حتی اگر `input()` داخل `try/except` باشد کار می‌کند و خروجی دقیقاً تا سؤال نشان داده می‌شود.

## راه‌اندازی (یک بار)

1. این شاخه را merge کن.
2. workflow با نام **Vendor Pyodide** خودش اجرا می‌شود و پوشه `vendor/pyodide/` (حدود ۱۰ تا ۱۵ مگابایت) را روی `main` می‌گذارد. اگر اجرا نشد: تب Actions ← Vendor Pyodide ← Run workflow.
3. چند دقیقه صبر کن تا GitHub Pages دوباره منتشر شود.
4. روی گوشی با اینترنت سایت را باز کن، به آزمایشگاه برو و یک بار کد را اجرا کن. از این به بعد آفلاین هم کار می‌کند.

تا وقتی مرحله ۲ انجام نشده، همه‌چیز مثل قبل از CDN بارگیری می‌شود (چیزی خراب نمی‌شود).

## محدودیت‌ها

- Pyodide همان CPython کامل نیست: threading، socket، tkinter، pygame و پکیج‌های native کار نمی‌کنند. کلاس‌ها، وراثت، `dataclasses`، `abc`، `enum`، `random`، `json` و بقیه کتابخانه استاندارد معمولی کار می‌کنند.
- بازپخش برای `input()` یعنی کار جانبی برنامه (مثلاً نوشتن در فایل مجازی) در هر پاسخ دوباره انجام می‌شود.
- مرورگرها می‌توانند cache را در کمبود حافظه پاک کنند؛ در آن صورت یک بار دیگر با اینترنت باز کن.
- حالت ناشناس (private) مرورگر cache را نگه نمی‌دارد.
